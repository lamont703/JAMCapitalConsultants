👋 Welcome to JAM Capital API Explorer

🚀 Quick Start:

  1. Authenticate: Enter your credentials in the sidebar and click "Login"
  2. Select Endpoint: Choose any endpoint from the categories
  3. Configure Request: Fill in the required parameters
  4. Send Request: Click "Send Request" to test the endpoint
  5. View Response: See the real-time API response below
